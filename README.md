Panel Adobe Premiere Pro 2024 untuk menyusun timeline dari EDIT_PLAN dan ANIMATION_PLAN, dengan satu preset BOTH per kemunculan aset. Target Windows 11, CEP + ExtendScript + FFmpeg hybrid.
