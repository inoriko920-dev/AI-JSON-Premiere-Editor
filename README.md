# AI JSON Premiere Editor

Plugin **Adobe Premiere Pro 2024** di Windows 11 untuk merakit sequence editable dari `EDIT_PLAN.json` dan `ANIMATION_PLAN.json` terpisah. CEP + ExtendScript + FFmpeg hybrid; **satu preset BOTH** (IN dan OUT) per kemunculan gambar.

**Status: STEP01 ASTRA — spesifikasi sedang ditutup, aplikasi BELUM diimplementasikan.** Pekerjaan dokumen ada pada [Draft PR #1](https://github.com/inoriko920-dev/AI-JSON-Premiere-Editor/pull/1). Branch masih belum di-merge ke `main`.
